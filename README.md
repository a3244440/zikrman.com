# ZIKR — сайт-каталог одежды

Монохромный сайт-каталог в стиле fashion-лендинга: анимированная главная, каталог с фильтрами, страница товара, избранное и админка для добавления вещей.

**Стек:** React 18 + TypeScript + Vite, Tailwind CSS 4, Motion (анимации), Supabase (база, вход админа, хранилище фото).

## Что есть

- **Главная**: заставка-загрузка со счётчиком; гигантский логотип ZIKR (по буквам), через который «проходит» фото (логотип инвертируется поверх снимка); при прокрутке буквы разлетаются в стороны; фото слегка двигается за курсором; бегущая строка ускоряется и меняет направление от скорости прокрутки; блоки и заголовки плавно появляются при прокрутке.
- **Каталог** `/catalog`, `/catalog/<категория>`: фильтры «Новинки» и «Скидки», сортировка, поиск (`?q=`).
- **Товар** `/product/<slug>`: галерея с зумом, цвета, размеры, кнопка «Заказать» (открывает WhatsApp с готовым сообщением, если указан номер, иначе Instagram), вкладки описания, похожие товары.
- **Избранное** `/wishlist`: хранится в браузере посетителя.
- **Админка** `/admin`: вход по email и паролю, список товаров, добавление, редактирование и удаление, загрузка фото перетаскиванием (сжимаются в браузере), смена порядка фото перетаскиванием, размеры, цвета, флаги «Новинка», «На главной», «В наличии».

## Запуск локально

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/
```

Без настроек сайт работает в **демо-режиме**: каталог берётся из `src/data/catalog.ts`, а правки в админке сохраняются только в вашем браузере.
Пароль демо-админки: `007`.

## Подключение базы (чтобы товары из админки видели все)

1. Создайте проект на [supabase.com](https://supabase.com) (бесплатного тарифа хватит).
2. **SQL Editor → New query** → вставьте весь файл `supabase/setup.sql` → **Run**.
   Он создаст таблицы, права доступа и хранилище фото, загрузит каталог (34 товара) и администратора.
   Пароль администратора задаётся в конце файла (`admin_password`, по умолчанию `007`).
3. **Project Settings → API** (или **Connect**): скопируйте **Project URL** и **publishable key** (`sb_publishable_…`, или старый `anon`)
   в `src/config.ts` → `supabaseConfig`. Это публичные значения, их можно хранить в коде.
4. (Желательно) **Authentication → Sign In / Providers** → выключите «Allow new users to sign up».

Вход в админку `/admin` — только по паролю, почту вводить не нужно. Пароль меняется в админке («Сменить пароль»).
Короткий пароль легко подобрать — лучше сразу сменить его на длинный.

Права проверяются на стороне базы (RLS): читать каталог может любой, а добавлять, менять и удалять товары и фото —
только пользователь из таблицы `admins`.

`supabase/schema.sql` и `supabase/seed.sql` — те же части по отдельности.

## Деплой

Подойдёт любой статический хостинг. Для Vercel и Netlify уже есть правила для адресов страниц (`vercel.json`, `public/_redirects`).
Vercel: Import Project → Framework «Vite» → добавить `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` → Deploy. Затем привяжите домен zikrman.com.

## Настройка под себя

- `src/config.ts`: название, слоган, валюта (сейчас $, как в каталоге Tilda), текст верхней строки, контакты (WhatsApp, телефон, Instagram, email) и категории.
- Логотип: `src/components/logo-paths.ts` (векторные контуры из `ZIKR_logo.pdf`); готовые файлы `public/images/brand/zikr-logo.svg` и `zikr-logo-white.svg`.
- Фото для главной: `public/images/brand/` (`hero.webp` — главное фото, `season.webp` — баннер «New Vibes», `detail-logo.webp` — блок «Миссия»).

## Каталог

34 товара и их фото перенесены со старого сайта на Tilda (`zikrmanbishkek.tilda.ws`):
- данные — `src/data/catalog.ts` (их же загружает `supabase/seed.sql`);
- фото — `public/images/products/<slug>/`, сжаты в WebP до 1200 px.

Описания на Tilda были почти у всех товаров пустые, поэтому короткие описания написаны по названию и фото. Таблицы размеров перенесены как есть. Цвета подобраны по фото.
